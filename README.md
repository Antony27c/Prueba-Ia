# Examen Multiple Choice

Aplicación web de examen tipo multiple choice con 20 preguntas organizadas en 3 unidades. Incluye un backend serverless en Vercel para feedback con IA via GroqCloud.

## Stack

- Frontend: HTML + CSS + JS vanilla (archivo único)
- Backend: Vercel Serverless Function (api/feedback.js)
- IA: GroqCloud API (llama3-8b-8192)
